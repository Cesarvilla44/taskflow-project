# Investigación de Tecnologías Backend-API

### 1. Axios
Es una librería cliente HTTP basada en promesas. Se utiliza para simplificar las peticiones al servidor, ya que maneja automáticamente la transformación de datos a JSON y ofrece una gestión de errores más robusta que `fetch`.

### 2. Postman
Es una plataforma para el desarrollo y prueba de APIs. Permite testear cada endpoint (GET, POST, DELETE, etc.) de forma aislada para asegurar que el backend funciona correctamente antes de conectarlo al frontend.

### 3. Sentry
Es una herramienta de monitoreo de errores en tiempo real. Notifica a los desarrolladores cuando ocurre un fallo en la aplicación, proporcionando detalles técnicos para corregirlo rápidamente.

### 4. Swagger
Es un conjunto de herramientas para documentar APIs. Genera una interfaz visual interactiva donde cualquier desarrollador puede consultar qué rutas existen, qué datos reciben y qué respuestas devuelven.
